## 架构说明

MCP 集成通过现有的 **fake-tool-call** 系统透明接入：
1. `buildToolsSuffix()` 在 agent 系统提示中列出所有 MCP 工具，格式与内置工具一致
2. AI 输出 `[TOOL:mcp__server__tool {...}]` 时，`parseFakeToolCalls()` 解析
3. `processFakeTools()` 识别 `mcp__` 前缀，通过 `onMcpToolCall` 回调路由到 `McpManager.callTool()`
4. 工具结果作为 delta 注入对话（AI 可在后续步骤看到结果）

MCP server 配置失败不阻断扩展激活，每个 server 独立初始化。
