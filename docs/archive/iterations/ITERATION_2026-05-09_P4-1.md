## 本次实现

### P4-1：`run_terminal` 工具（Agent 可执行终端命令）

AI 在 agent 模式下可通过 fake-tool 调用终端命令，用于编译验证、运行测试等。

**格式：**
```
[TOOL:run_terminal {"command":"npm run build","workdir":"/可选/绝对/路径"}]
```

**流程：**
1. `agent-loop.ts` 的 `buildToolsSuffix()` 将 `run_terminal` 写入系统提示的工具列表
2. `processFakeTools()` 识别 `run_terminal` 调用，调用 `callbacks.onTerminalCommand`
3. `extension.ts` 的 `onTerminalCommand` 回调：
   - 非 autopilot 模式：弹出 `showWarningMessage` 请用户确认
   - 调用 `runCommand()` 执行命令，结果格式化后注入为 delta
4. Agent 下轮可见命令输出，继续推理

### P4-2：Token 用量显示

非 agent 模式下，每次 AI 回复底部显示 `↑N ↓M tokens`（prompt/completion token 数）。

**流程：**
- Provider 层（`deepseek-api.ts`、`openai-compat.ts`）从 API 响应提取 `usage` 字段
- 通过 `LLMChatOptions.onUsage` 回调上报 `TokenUsage { promptTokens, completionTokens, totalTokens }`
- `routeChat()` 将 `opts.onUsage` 传给 provider
- 主聊天调用在 `onUsage` 中 postMessage `{type:'tokenUsage', promptTokens, completionTokens}`
- Webview 存入 `pendingTokenUsage`，`endResponse` 时渲染 `.token-usage-row` 小标签
