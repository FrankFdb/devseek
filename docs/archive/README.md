# DevSeek 文档归档

本目录保存历史报告、专项分析、测试计划、竞品长参考和阶段性迭代纪要。归档文件默认只读，不再作为日常开发入口。

## 分类

| 目录 | 内容 |
| --- | --- |
| `reports/` | 审计报告、GitHub 同步报告 |
| `agent/` | Agent 专项审计、实测报告、路径/会话分析、竞品工作流长参考 |
| `architecture/` | 旧架构方案、重构迭代记录 |
| `intent-recognition/` | 意图识别测试报告 |
| `iterations/` | Sprint 和专题迭代纪要 |
| `testing/` | 一次性测试计划 |
| `ui/` | 旧 UI 风格指南、显示风格长参考 |
| `plans/` | 历史优化计划 |

## 使用规则

1. 查历史事实可以读归档。
2. 发现仍有效的设计约束，应迁移到 `docs/README.md` 列出的活跃文档。
3. 不在归档文档里继续追加新任务状态。
