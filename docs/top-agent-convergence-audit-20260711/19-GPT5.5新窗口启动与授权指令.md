这段授权只绑定当前窗口、`CLOSE-01`、所观察到的 stale runtime 和上述动作范围。它不授权 `CLOSE-02` 的编程 probe，也不授权真实 Provider 或外部操作。

若随后用户决定执行 `CLOSE-02`，必须另行查看其作业卡，并针对指定 prompt marker、Provider action、隔离 probe path、验证和 cleanup 给出新的明确授权；不得复制 `CLOSE-01` 的授权。
